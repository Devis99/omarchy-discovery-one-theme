# Discovery One

A dark Omarchy theme inspired by the clean geometry, practical futurism, and
quiet unease of *2001: A Space Odyssey*.

## Emotional target

**Should feel:** precise, spacious, calm, expensive, clinical, curious, and a
little uncanny.

**Should not feel:** cyberpunk, gamer-RGB, neon, glossy-gradient, militaristic,
or like a generic black-and-red hacker theme.

## Visual thesis

The desktop is a spacecraft at the edge of the void: graphite panels, cool
blue-green instrument shadows, warm ivory text, phosphor display colours, and
one red indicator light. The red is a signal, not wallpaper. The sparse palette
leaves room for windows and wallpapers to provide depth.

## Roles

| Role | Material / use |
|---|---|
| Background | Near-black graphite / deep space |
| Surfaces | Slightly lighter molded-panel grey |
| Text | Warm spacecraft ivory |
| Muted text | Cool instrument-panel blue-grey |
| Lead accent | HAL-like signal red for focus and active state |
| Support | Muted amber for secondary information |
| ANSI blue/cyan | Phosphor display colours, kept inside the screen language |
| Terminal surfaces | Screen-black teal, with mint/green information text |
| Warning/error | Red; reserve it so it keeps its authority |

## Terminal direction

Terminals should feel like the ship's instrument displays rather than a generic
retro computer theme. Use the near-black teal background, mint/green for normal
screen data, amber for secondary telemetry, red for warnings, and occasional
pink/violet for diagram-like output. Keep ivory for the prompt and primary text;
do not turn every terminal line green.

## Wallpapers

The installed wallpaper set lives alongside the theme in `backgrounds/`. It is
narrowly curated to spacecraft, orbital stations, and the film's instrument
screens. The generated vector studies and weaker interior/lifestyle frames were
removed. These copyrighted stills are for local personal use and must not be
redistributed.

## What to avoid

- Do not turn every element red.
- Do not add cyan/magenta glow effects.
- Do not use pure black everywhere; the blue-green graphite is part of the
  material.
- Do not turn the whole interface red.
- Keep text contrast readable even when preserving the soft, spacious feel.
